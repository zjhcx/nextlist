# 外观设置

在文件页面右侧工具栏打开「本地设置」，顶部的「外观 · Appearance」支持：

- 背景图片：填写可直接访问的 HTTP / HTTPS 图片地址，也支持站内相对路径。
- 主题色：预设色板或自定义取色，作用于全站（媒体库页面优先使用媒体主题色）。
- 卡片透明度：30%–100%，调节文件区、导航、弹窗、菜单和后台面板。
- 组件透明度：30%–100%，调节按钮、输入框、下拉框和提示卡片等组件背景。
- 磨砂模糊：0–32px。
- 恢复默认：清空图片，恢复纯灰背景、100% 不透明度和 0px 模糊（默认不启用毛玻璃）。

设置自动保存在当前浏览器，无需后台配置。图片无法加载时仍显示默认纯灰背景。
明暗主题随现有主题开关切换；不支持 backdrop-filter 的浏览器使用不透明面板。
系统启用「减少透明度」时，面板自动改为不透明。
